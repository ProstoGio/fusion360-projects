# 🧊 Fusion360 Projects

A collection of 3D models and mechanical designs built in Autodesk Fusion 360 — from concept sketches to print-ready geometry.

Each project folder includes the exported model files, renders or photos, and a short write-up covering the design process and techniques used.

---

## 📁 Structure

Each project lives in its own folder under `projects/`:

```
projects/
└── project-name/
    ├── model.stl        → interactive preview (renders inline on GitHub)
    ├── model.step        → editable, tool-agnostic CAD format
    ├── render.png         → screenshots or turntable renders
    └── README.md         → design notes, techniques, and print details
```
