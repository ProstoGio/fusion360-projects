# Golden Mug
A 3D-printable model of a mug featuring an embossed "JinJii" logo and an integrated handle.

## Overview
This project consists of a 3D model designed for additive manufacturing. The design includes a cylindrical body with an embossed "JinJii" wordmark on the exterior surface and a functional handle.

## Files
| File | Description |
| :--- | :--- |
| golden-mug.step | The primary CAD model for editing or reference. |
| golden-mug.stl | The mesh file prepared for 3D printing. |
| render.png | A visual representation of the final design. |

## Notes
* The model includes an embossed "JinJii" text element on the surface.
* The design features an integrated handle.
* Suitable for 3D printing applications.
