# Impossible Cube
A 3D-printed model of Escher's impossible cube illusion, my first Fusion 360 project.

---

## Overview

A physical rendition of M.C. Escher's impossible cube — an optical illusion where the geometry appears structurally inconsistent from certain viewing angles, despite being a fully valid 3D object.

## Files

| File | Description |
|---|---|
| `impossible-cube.stl` | Print-ready mesh, viewable directly in-browser on GitHub |
| `impossible-cube.step` | Editable parametric model for use in other CAD software |
| `render.png` | Render/photo of the finished model |

## Notes

- Modeled entirely in Autodesk Fusion 360
- 3D printed to verify the design translated correctly from screen to physical object
