# iPhone 16 Case
A 3D-printable protective case designed for the iPhone 16 using Autodesk Fusion 360.

## Overview
This project serves as a CAD exploration for the iPhone 16 form factor. The model was developed in Autodesk Fusion 360 with the intent of achieving precise dimensional accuracy for a functional, handheld case.

## Files
| File | Description |
| :--- | :--- |
| iphone-16-case.step | The master CAD assembly file for further modification. |
| iphone-16-case.stl | The exported geometry ready for slicer software. |

## Notes
* Model dimensions are based on original design measurements; some minor variances in length may exist.
* The design was created as a personal study in precision modeling for handheld hardware.
