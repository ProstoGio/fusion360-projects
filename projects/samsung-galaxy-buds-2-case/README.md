# Samsung Galaxy Buds 2 Case

A protective 3D-printable case model designed for the Samsung Galaxy Buds 2 charging enclosure.

## Overview

This project provides a 3D model of a protective case for the Samsung Galaxy Buds 2. The geometry was developed by importing calibrated orthogonal reference images into Autodesk Fusion 360 to map the device's organic shape. It serves as a study in modeling non-standard, contoured forms.

## Notes

*   Dimensions were derived from calibrated photographic references rather than official manufacturer schematics.
*   The project was initiated using the known exterior box dimensions (50 x 50.2 x 27.8 mm) as a scale baseline.
*   Final tolerances may require minor adjustment due to the complex, non-linear curvature of the original device.
