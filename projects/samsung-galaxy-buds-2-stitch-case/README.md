# Samsung Galaxy Buds 2 Stitch Case
A protective 3D-printable case for Samsung Galaxy Buds 2 featuring an engraved Stitch character face on the top lid.

## Overview
This project provides a custom protective shell for the Samsung Galaxy Buds 2 charging case. The design incorporates an engraved Stitch face on the top surface. It is a iteration of previous case designs, with future updates planned to include integrated 3D ears.

## Files
| File | Description |
| :--- | :--- |
| `case.step` | The primary 3D CAD model for editing in Fusion 360. |
| `case.stl` | The mesh file ready for slicing and 3D printing. |
| `render.png` | A visual preview of the case design. |

## Notes
* The current design features an engraved face on the top shell.
* Future revisions are intended to include physical 3D-modeled ears.
