# Simple Footwear
A miniature footwear model created as a practice exercise in Autodesk Fusion 360.

## Overview
This project represents an initial attempt at modeling footwear geometry within Fusion 360. The design was developed using visual alignment to achieve proportional accuracy rather than precise measurement, and is intended as a miniature display figure rather than functional, human-scale footwear.

## Files
| File | Description |
| :--- | :--- |
| footwear.stl | The 3D model exported for printing. |
| footwear.step | The CAD source file for reference or editing. |
| render.png | A visual preview of the footwear figure. |

## Notes
* The model was designed using manual visual alignment.
* This is a miniature figure and is not sized for actual human wear.
* Created as an introductory practice exercise in Fusion 360.
