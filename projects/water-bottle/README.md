# Water Bottle

A 3D model of a standard water bottle featuring a functional cap and thread design.

## Overview
This project serves as an exploration of CAD modeling for standard consumer packaging, specifically focusing on the implementation of bottle threads. The design was based on general reference dimensions, though users should be aware that the thread tolerances between the cap and bottle neck may require adjustment.

## Files
| File | Description |
| :--- | :--- |
| water-bottle.step | The primary 3D model file for the bottle and cap assembly. |
| water-bottle.stl | A triangulated mesh version of the model ready for slicing. |
| render.png | A visual representation of the final design. |

## Notes
* Dimensions were sourced from "dimensions.com".
* The design includes integrated threads, though the chosen radii for the cap and bottle neck may contain dimensional inaccuracies.
* Users should verify thread fitment before printing.
